# Sistema de Registro e Acompanhamento de Atividades Físicas – PSE

## Descrição

Projeto de sistema desenvolvido no contexto do **Programa Saúde na Escola (PSE)**, com o tema **Promoção da Atividade Física no Ambiente Escolar**. Este repositório reúne a documentação referente à 1ª etapa do projeto (2026), contendo a contextualização do programa, a definição do sistema proposto e demais entregas solicitadas.
